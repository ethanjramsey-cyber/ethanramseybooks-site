# ethanramseybooks.com (static preview)

A static site for books by Ethan Ramsey. Open `index.html` via a local web server (not as a file:// URL, so root-relative paths work). See `DEPLOY.md` for later hosting on Cloudflare Pages or GitHub Pages.

Replace `{MAGNET_URL}` with the MailerLite landing-page URL before going live. Do not deploy from this folder until the preview has been approved.
